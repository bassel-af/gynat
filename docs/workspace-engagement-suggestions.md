# Workspace engagement suggestions

Based on production data pulled 2026-08-18 (28 workspaces, 51 users). Not confirmed with a large sample — few users, so treat as directional, not definitive.

1. **Fix the empty-space problem** — 43% never add a single person. A guided "add your first person" nudge (or a faster import path) right after workspace creation would likely have the biggest impact of anything on this list.
2. **Push invites earlier** — multi-member spaces are clearly stickier. Prompting new creators to invite family before or right after they start the tree could turn more solo attempts into collaborative ones.
3. **Don't invest more in collections/branch pointers/rada'a for now** — real usage is near zero; they're not the current bottleneck.
4. **Think about re-engagement** — almost nobody returns for a second editing session. A simple "your tree is waiting" nudge a few days after the first session could recover some of that drop-off.
